Client-side Media & Code Transformation Platform

Download & Installation für alle Systeme

Diese Anwendung ist als Cross-Platform PWA konzipiert. Du kannst sie auf jedem System ohne Emulation direkt installieren:

Windows x64 / x86 / x32 macOS (Intel / Apple Silicon) Linux (.desktop) iOS / iPadOS Android (APK Package)
Installations-Anleitung:
• Windows/Mac/Linux: Klicke oben rechts im Browser auf das "Installieren"-Symbol in der Adressleiste.
• iOS (Safari): Teilen-Button → "Zum Home-Bildschirm".
• Android (Chrome): Menü (3 Punkte) → "App installieren".

1. Universal Code Transpiler

2. Media & Screensaver Engine

Bereit. Keine Serverübertragung.

3. Archive Extract & Binary Inspector

Wähle ein ZIP-Archiv aus.
